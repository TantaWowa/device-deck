Check Apple menu → About This Mac if you are unsure. All releases, checksums and build metadata.

Unsigned beta installers. macOS may block the installer or app. After trying to open a download you trust, go to System Settings → Privacy & Security and choose Open Anyway for that item. Apple's instructions. Managed Macs may need administrator approval.

From download to your first device

  1. Open the downloaded .pkg and follow the installer. Node, the capture helper, dashboard, CLI, TUI and MCP server are included.
  2. Open Device Deck in Applications. Use its menu-bar icon to open the local dashboard.
  3. Choose Devices → Discover / add devices, add your devices, and reserve one to open its controls. Allow Camera access for capture cards and Local Network access for discovery when requested.

Add only the tools you need

Recording, keypress overlays, USB screenshots and video encoding require FFmpeg. If you use Homebrew, run brew install ffmpeg-full. If diagnostics cannot find it, set the FFmpeg and ffprobe executable paths in Settings using the directory printed by brew --prefix ffmpeg-full.

Android needs platform tools and debugging authorization. Apple simulators need Xcode and runtimes; touch needs idb. Physical Apple TV needs pyatv and pairing. Read the full setup guide for platform details.

Run devdeck doctor to check your setup. No terminal is needed to open the app or dashboard.

Keep Device Deck up to date

Run devdeck update check, then devdeck update download. Downloads are verified against their GitHub SHA-256 digest and size. Finish sessions and recordings, quit the app, then open the new installer. Your configuration and captures stay in place.

Upgrading from a licensed beta? Download this free installer manually once. The old updater checks a different download service.

Build it yourself

The complete source is available under MIT. Source builds need Node 24 or later and Xcode command-line tools. Follow the build instructions.
