Install and set up

The installer includes Node, FFmpeg, ffprobe, the camera helper, dashboard, CLI, TUI and MCP server. Normal installation and bundled recording need no Terminal commands or Homebrew.

  1. Install the package and open Device Deck from Applications.
  2. Sign in as the Mac account that owns your SDKs and devices. Choose Start shared service in setup and approve the macOS administrator prompt.
  3. Keep Open menu-bar app at login selected. Allow Camera access for USB capture, then choose Open dashboard and add your devices.

The shared service starts when macOS boots, after any required FileVault disk unlock. Its one inventory and reservation store serve every account you allow under Mac setup… → Mac account access, including an existing CI runner account. Their CLI and MCP connections discover the service automatically.

Quitting the menu-bar app leaves the core service running. USB capture and Apple simulator features need a usable host desktop; USB capture also needs the host's menu-bar camera bridge. Open at login controls that app, not the boot service.

The Check for updates… flow downloads a verified installer, waits for all accounts' active work to finish, then requests administrator authorization to install and restart the shared service. Configuration and captures stay in place.

Moving from an older beta

Version 0.9.0-beta.2 and earlier packages are unsigned and use the old startup and update flow. Download the new signed installer manually once, finish device sessions and recordings, and quit the old app before installing. Complete Mac setup after installation. See the older-beta notes for existing startup configurations.

Add only the device tools you need

Android needs platform tools and debugging authorization. Apple simulators need Xcode and runtimes; touch needs idb. Physical Apple TV needs pyatv and pairing. Configure these in the hosting Mac account. Shared API access does not merge simulator homes; native CI tools targeting the host's simulators must run under that account too.

Read the full Mac setup guide for permissions, account access and platform details.

Build it yourself

The complete source is available under MIT. Source builds need Node 24 or later and Xcode command-line tools. Follow the source-build instructions, or build a Mac package with bundled recording tools.
