Install and set up

Node, FFmpeg, ffprobe and the dashboard are included. Normal installation and setup need no Terminal commands, Homebrew, restart or logout.

  1. Open the downloaded installer and follow its prompts. Open Device Deck from Applications in the Mac account that will host your devices and SDKs.
  2. Choose Start shared service and approve the macOS administrator prompt. The service starts immediately.
  3. Keep Open menu-bar app at login selected and allow Camera access if you use USB capture. Choose Open dashboard, then Devices → Discover / add devices.

Follow the full Mac setup walkthrough for permissions, your first device and any additional platform tools.

One service for your Mac accounts

Under Mac setup… → Mac account access, allow existing accounts such as ci-runner. Their app, CLI and MCP connections discover the same inventory and reservations automatically.

The core service starts at boot, before account login and after any required FileVault disk unlock. Quitting the menu-bar app leaves it running. Open at login controls only the menu-bar app. USB capture needs the hosting account logged in with that app running; Apple simulator features also need a usable host desktop.

Update from the app

Choose Check for updates… → Download update → Install and reopen, or Install when idle to wait for every account's reservations and recordings to finish. Approve the administrator prompt to update the shared service. Configuration and captures stay in place.

Moving from an older beta

Version 0.9.0-beta.2 and earlier packages are unsigned. Download the signed installer above once, finish sessions and recordings, and quit the old app before installing. Then complete Mac setup. Read the older-beta migration notes.
