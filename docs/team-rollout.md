# Set up Device Deck for a team

Device Deck is free and open source under the MIT license. All features, concurrent sessions and recording annotations are available without a license key or subscription.

Start with the [Mac install guide](install.md). It distinguishes the current public unsigned beta from the next signed installer, including their different recording tools, service setup and update procedures. Use the instructions for the package you install.

Choose the setup that matches how the team works:

- For several macOS accounts on one Mac, follow [Mac account access](install.md#allow-another-mac-account) when using a package with the new shared service.
- For another Mac's devices, use [Deck sharing](deck-sharing.md). Each host retains its own reservations and captures.
- For browser access from another machine, see [remote access](remote-access.md).
- For CI and coding agents, use [device groups](group-reservations.md) with the existing test runner.

Device reservations enforce exclusive ownership and expiry. Local use needs no Device Deck account; the optional web portal uses account sign-in. See the [documentation index](README.md) for device setup, capture workflows and platform limits.
